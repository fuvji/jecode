Questions

Before you start.

Which systems are supported?

Windows 10 and 11 on x64 or ARM64, macOS 12 and newer on Apple silicon or Intel, and Linux on x64 or ARM64. SteamOS is detected as an immutable Linux system and installs entirely under your home directory.

Does the installer change my system?

No. It reuses an existing Bun installation and otherwise installs one beside the app. It never writes outside your user directory and never adds a background service.

What does the update button update?

It updates jetcode itself: the desktop shell, the CLI, the core and the bundled web UI. It never pulls an upstream OpenCode release over your install. On systems without the desktop installer, run the install command again and it updates the existing checkout.

Can I use it without a hosted model?

Yes. jetcode discovers Ollama, LM Studio and any OpenAI-compatible server on this machine, then falls back locally when the network or your picked model is unavailable.
