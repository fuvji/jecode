A working partner, not a chat window.

jecode keeps a real session over your working tree. Every step is visible, every change lands in a file you can review, and the shell is one tool call away.

Reads the whole project

Search, glob, and file reads run against the repository you point it at. It follows imports and checks its assumptions before editing.

tools · read · grep · glob · list

Edits and verifies

Changes are patches, not rewritten files. It can run the test suite, a typecheck, or a single command to prove the change holds.

tools · patch · shell · task

Lives where you work

The same session runs in the terminal UI and the desktop app. Bring your own provider key, or point it at a local endpoint.

agents · build · plan · general

Build it from source.

The repository is a Bun workspace. The CLI build embeds the web UI; the desktop build wraps it in Electron. 

git clone https://github.com/fuvji/jecode.git
cd jecode
bun install
bun --cwd packages/cli build --single --baseline
bun --cwd packages/desktop build

Needs Bun 1.4.4. A release build wants your own Ed25519 key and integrity manifest; a development build does not.
